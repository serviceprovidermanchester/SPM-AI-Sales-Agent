# User guide

## Log in and read the dashboard
Use the password generated by `python scripts/bootstrap.py`. The four headline counters show all leads, hot leads, due follow-ups and won deals. A lead is hot when its score is 75–100; these are **rules**, not ML predictions.

## Capture a new inquiry
Select **Add lead**, enter company, contact and at least one of email/phone, then service, expected budget, timeline and source. Optional description and consent record can be included. Saving immediately calculates a lead score.

Alternatively open **Public lead form ↗**. This saves an inquiry without logging in, provided the form is enabled. Use fictional information for portfolio demos.

## Find and update a lead
Search company/contact/email; filter by pipeline status or priority. Click **View →** for details. Update the pipeline status or use the date-time picker to set a follow-up. Save changes. The dashboard updates due follow-ups as the dates pass; the app does not send notification emails.

## Understand scoring
The lead detail pane shows contributions from budget, timeline, service interest and source. Example: `5000-15000` budget +22, `30-days` +21, `ecommerce` +14, `referral` +15, total 72/100 (warm). See `docs/PRD.md` for all rules.

## Write follow-ups
**Generate template** produces local, editable sales copy. **Generate with AI** requires an OpenAI API key in `.env` and a checkbox confirming that limited context may leave your system. Both approaches **generate text only**. Always fact-check and manually send through your authorized communications channel.

## Notes and cleanup
Write internal conversation summaries in the activity timeline. Download a CSV export from the top of the dashboard if you need a local report. Deleting a lead also deletes its activity log. Exported copies must be managed separately.

## Common limitations
One admin account; no role management; no live email/SMS/WhatsApp integration; no external lead enrichment; no auto-contact; no invoicing; no metrics tied to real advertising channels. Treat as a tested software demonstration, not a finished commercial system.
